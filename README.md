### ✨ Features

* 🔍 **Search Banner:** Prominent hero section with interactive search input.
* 📦 **Topic Cards Grid:** Responsive grid showcasing help topics (Branches, Account, Billing, Organizations, etc.).
* 🎨 **Interactive Hover Effects:** Smooth CSS transitions on cards and buttons.
* 🦶 **Multi-Column Footer:** Structured site map footer section.
